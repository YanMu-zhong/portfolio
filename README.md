# 分析作品集

本仓库收录我的产品与数据方向的分析作品。每份作品遵循同一套结构：**从定义问题开始 → 建立可验证的指标或机制 → 用数据得出结论 → 明确说明方法边界**。

## 作品结构

### 体系：个人养老金产品 — 方案设计与规则体系

同一个业务问题下的两份文档，分上下两层：上层定义"为什么做、用户如何被服务、会带来什么副作用"，下层定义"什么算合格"。

| 层级 | 文件 | 内容 |
|---|---|---|
| 上层 · 方案设计 | [`pension-product-mechanism.html`](pension-product-mechanism.html) | 问题定义 / 方案选型（为什么是 ETF）/ 用户决策路径 / 准入·推荐·生命周期三层机制 / 流程与多方职责 / 风险与投资者教育 / 验证方案 |
| 下层 · 规则定义 | [`etf-screening.html`](etf-screening.html) | 9 项指标及阈值推导 / 数据口径 / 1011→770→72 筛选链 / 优先级与退出条件 / 交付局限 |

### 深度拆解

| 文件 | 内容 |
|---|---|
| [`shenzhen-expressway.html`](shenzhen-expressway.html) | 业务结构拆解：用毛利贡献而非收入占比衡量真实盈利驱动，验证"双主业"描述与利润结构的落差，追溯利润波动来源，并用后续年度数据回测结论 |

## 关于数据处理

- 所有数据均来自**公开披露信息**（公司年报、半年度报告、公开金融数据终端、公开报道）
- 涉及第三方研究报告的作品**已做匿名化处理**，不包含任何个人或机构身份信息
- 页面中的图表：流程图来自原始报告，数据图由本人基于底层数据用代码重绘

## 技术说明

单页 HTML + 内嵌 CSS，无外部依赖，可直接通过 GitHub Pages 访问，也支持弱网与移动端浏览。

- 无 JavaScript
- 响应式布局，表格支持横向滑动
- 图表使用原生 SVG 与 CSS 绘制
